# 🛒 Blinkit Customer Behaviour Analysis

## 📌 Project Overview

This project focuses on analyzing Blinkit's customer purchasing behaviour using SQL and Power BI. The objective is to understand customer buying patterns, product demand, sales trends, payment preferences, and city-wise performance to support business decision-making.

---

## 📊 Tools Used

- SQL (MySQL)
- Power BI
- Microsoft Excel

---

## 📂 Dataset

The dataset contains customer purchase information including:

- Customer ID
- Customer Name
- City
- Age
- Gender
- Product Category
- Item Purchased
- Quantity
- Total Price
- Payment Method
- Purchase Date
- Discount
- Delivery Status

---

## 🔍 SQL Analysis

The following business questions were answered using SQL:

- Total Orders

- City-wise Sales Analysis

- Discount Analysis
- Repeat Customers
